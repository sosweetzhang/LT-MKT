1. The question text: <question text>

4. Candidate knowledge concepts from the same and different domains: <candidate concepts>

1. Identify prerequisite knowledge concepts within the same domain that are necessary for understanding the main knowledge concept.

Ensure that:
- Prerequisite relations represent learning dependencies within the same domain.
- Correlation relations represent semantic or functional associations across domains.
- The output contains only concepts selected from the candidate concepts.
- The generated relations are educationally meaningful and logically consistent.

Return the response strictly in the following format without additional explanation:

{
"question text": <question text>,
"main knowledge concept": <main knowledge concept>,
"prerequisite": <prerequisite concepts>,
