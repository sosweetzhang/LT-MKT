# Incorporating Cognitive Load and Knowledge Transfer for Multi-Domain Knowledge Tracing


This repository contains the core implementation for the paper titled **Incorporating Cognitive Load and Knowledge Transfer for Multi-Domain Knowledge Tracing**, accepted as a `CIKM 2026` **Oral** [[Paper](http://arxiv.org/abs/2608.24005)]. 

Authors: [Haotian Zhang](https://scholar.google.com.hk/citations?user=N3V-QjAAAAAJ&hl=zh-CN), Shucun Wang, Jinze Wu,et al.
